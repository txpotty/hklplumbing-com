    Combination Sump Pump Systems in Hawaiian Paradise Park

    Combination units pair a primary pump and a battery backup on one pre-plumbed discharge assembly. We set them in homes that want two layers without a bigger pit.

    Battery Backup Sump Pump Systems in Hawaiian Paradise Park, HI

    Backup systems we install use sealed AGM batteries that do not need water.     Submersible Sump Pump Installation in Hawaiian Paradise Park

    Submersible pumps live at the bottom of the pit with a sealed, oil-cooled motor. Because the motor is cooled by the surrounding water, they run quieter and can push more gallons per minute up a tall lift than most pedestal pumps. The pit lid sits flush. Each install gets a sealed lid and a grommet around the cord to keep out radon and odor.
