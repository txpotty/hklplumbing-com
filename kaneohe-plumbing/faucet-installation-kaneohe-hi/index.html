    Wall-Mount Faucet Installation in Kaneohe, HI

    Wall-mount faucets start before the drywall closes. We set the rough valve for the sink height and the finished wall depth, because a valve set a half inch too deep leaves the trim floating off the tile. Trim goes on after tile. You get a clear deck with no faucet base to wipe around.

    Touchless Faucet Installation in Kaneohe

    Touchless faucets run on a solenoid valve. The control box mounts under the sink, up off the cabinet floor where a small leak will not soak it, and it runs on batteries or a plug-in transformer. Mineral scale can stick a solenoid open, so we add the inline strainer the maker supplies. We test the sensor range last.
