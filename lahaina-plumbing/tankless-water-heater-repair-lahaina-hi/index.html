    Rinnai Tankless Water Heater Repair in Lahaina, HI

    Rinnai units are common, and most of their trouble starts with scale. The LC code is the unit's own warning that the exchanger needs a flush. We also see dirty flame rods behind a code 11 or 12 and tired combustion fans behind a code 61, and we test every one against Rinnai's published values. Parts come from the factory list.

    Igniter & Flame Rod Repair in Lahaina, HI

    Gas tankless heaters light with a hot surface or spark igniter, then prove flame with a flame rod. An oxidized flame rod gives a weak microamp reading and the board shuts the gas valve after a few seconds. We clean or replace the rod, look for a cracked igniter or a lazy spark, and confirm the gas valve opens on call. Five-minute fix sometimes.

    Tankless Error Code Diagnostics in Lahaina, HI

    Every tankless brand flashes its own codes, so a code 11 on one unit means something else on another. A Rinnai 11 is no ignition, a Navien E003 is ignition failure, and a Noritz 11 is also an ignition fault, yet the checks behind each one are not the same. We read the code, pull the history and test the part tied to it. Guessing gets expensive.

    Navien Condensate and Fan Repair in Lahaina

    Navien's E016 is a heat exchanger overheat, and it usually traces to scale or a backed-up condensate line. We also read fan speed from the service menu and compare it to spec, since a fan that cannot reach target RPM will cause flame and exhaust faults on the same unit. We clean the trap and screen, then retest.

    Flow Sensor and Thermistor Repair in Lahaina

    Tankless heaters start when the flow sensor sees about half a gallon a minute, then trim the burner using thermistor readings. A dirty inlet screen or a failing sensor shows up as no hot water, temperature swings or a unit that drops out mid-shower. Our tech cleans the screen, checks sensor values in the service menu and tests thermistor resistance against the chart. Usually under an hour.

    Rinnai Error Code Repair in Lahaina

    Rinnai owners usually call about a code 10, which points to an air supply or exhaust blockage. We check the vent terminal for bird nests and dryer lint, then pull the front cover to inspect the intake screen and the combustion fan. Vent runs longer than the manual allows can trigger it too. We measure.
