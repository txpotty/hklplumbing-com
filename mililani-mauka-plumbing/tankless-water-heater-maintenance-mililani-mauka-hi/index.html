    Tankless Error Code Diagnosis in Mililani Mauka, HI

    An error code is the heater telling you what it saw. Rinnai LC codes point to scale, Navien E003 is a failed ignition and Noritz 90 points at combustion air or exhaust trouble. First we read the code history. If a part has failed, you hear the repair and the price before we start.

    Rinnai Tankless Service in Mililani Mauka

    Rinnai units tell you a lot through the controller. A code 11 is a failed ignition, while code 12 is a flame that lit and then dropped out. On a Rinnai visit we clean the air intake filter and check the flame rod for soot or cracks.
